One line roasting a smart fridge that locked the ice cream behind a
quiz about its owner's life choices — and the owner has failed it four
nights in a row.

Entered in [Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/c/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9)
on [make.fun](https://make.fun).

`main.py` (Python 3.13, no dependencies) writes the roast to
`/output/entry.txt`. Run it with:

```sh
python3 main.py
```

The output is deterministic: every run writes the same 116 characters.
